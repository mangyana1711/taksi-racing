# TAKSI RACING 🚕
Prototipe game simulasi taksi 3D yang bisa dimainkan lewat browser Android dan PC.

## Fitur
- Kota 3D dengan beberapa wilayah: pusat kota, kampung, industri, dan pinggir danau.
- Kontrol layar sentuh untuk gas, rem, dan belok.
- Kamera belakang dan kamera kabin.
- Jemput penumpang di marker hijau, antar ke marker biru, lalu dapat bayaran.
- Saldo awal Rp125.000, bengkel, upgrade mesin/ban/rem, servis, dan pilihan mobil.
- Keyboard PC: WASD atau tombol panah; C untuk kamera; G untuk bengkel.

## Publish lewat GitHub Pages
1. Buka tab **Settings** pada repository ini.
2. Pilih **Pages**.
3. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu tekan **Save**.
5. Tunggu beberapa menit sampai status deployment selesai.
6. Game akan tersedia di: https://mangyana1711.github.io/taksi-racing/

## Cara main
1. Buka link game di Chrome Android; mode lanskap disarankan.
2. Tekan **MULAI MENYETIR**.
3. Tahan **GAS** untuk maju, **REM** untuk mengurangi kecepatan, dan tombol panah untuk belok.
4. Dekati marker hijau untuk menjemput penumpang.
5. Antar ke marker biru untuk menerima bayaran.
6. Gunakan **BENGKEL** untuk servis, upgrade, atau membeli mobil.

## Catatan
Ini adalah prototipe web 3D, bukan APK Android native. Grafik kota dibuat dari bentuk 3D sederhana. Game memerlukan internet untuk memuat pustaka Three.js dari CDN jsDelivr dan sebaiknya diuji pada perangkat Android.
